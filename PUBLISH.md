# Как открыть лендинг для посетителей

Этот репозиторий содержит только описание программы, картинки и инструкции. Код приложения и рабочая база размещены отдельно.

1. Создайте публичный репозиторий `service-workshop-site` в аккаунте владельца.
2. Загрузите файлы этой папки в корень репозитория, включая `images`, `docs` и `.nojekyll`.
3. Откройте Settings → Pages.
4. В Source выберите Deploy from a branch, ветку `main`, папку `/ (root)` и нажмите Save.
5. Дождитесь публикации и откройте адрес, который покажет GitHub. Ожидаемый адрес для этого имени: `https://vanssk8hai.github.io/service-workshop-site/`. До успешной публикации адрес может быть недоступен.

Альтернатива — отдельный сайт Netlify с этими файлами в корне. Не загружайте лендинг вместо действующей программы мастерской.
