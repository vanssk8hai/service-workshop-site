# Размещение

GitHub Pages публикует ветку main из корня. Сайт содержит описание, инструкцию и чистую офлайн-программу в downloads/.

После изменения программы обновите HTML и ZIP в downloads/. Заказы, личные настройки и онлайн-подключение сюда не добавляйте.

robots.txt и sitemap.xml разрешают индексацию описания и инструкции; появление в поиске зависит от поисковой системы. Владелец может добавить сайт в Google Search Console и отправить sitemap.xml.

На GitHub Pages проект размещён в подпапке. Google читает robots.txt с корня домена, поэтому файл в подпапке не управляет обходом всего домена. Для обнаружения sitemap отправьте его полный URL через Google Search Console; метаданные страниц уже разрешают индексацию.
